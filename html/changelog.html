🚀 Version 2.0.0 — Don't Lose Your Tabs Anymore!

  • Fixed critical bugs with disappearing favicons and loss of access to tabs after browser restart.
  • Fixed empty popup window that sometimes appeared instead of the extension menu.
  • Fixed "Could not establish connection" errors during browser startup — suspended tabs now initialize correctly.
  • Fixed multiple runtime errors improving background stability.
  • Improved localization and added a language selector to Settings.
  • Added automatic tab backups — once a week by default. Can be disabled or adjusted in Settings.
  • Added Discard Only mode — URLs are never replaced, but with less control: tabs always unsuspend on switch (Chrome API limitation), favicons don't change, screenshots are not available, etc. For those who prefer to see the original URLs — tab loss due to extension removal or the extension itself is impossible in this mode.
  • Automatic migration of tabs from other suspenders (The Great Tab Killer, Marvellous Suspender, etc.) on first install — your tabs won't be lost when switching.
  • Improved recovery page styling and localization.
  • Focused on the main complaints and, it seems, fixed most of them — added different solutions for different needs.

June 9, 2025

🎂 The Great Tab Killer for Manifest V3

  • Rebuilt from the ground up for Chrome Manifest V3 — the current and future extension standard.
  • Automatic tab suspension after a configurable delay: 1 minute, 5 minutes, up to 2 weeks, or never.
  • Smart exceptions — never suspend:
    • Pinned tabs
    • Tabs playing audio
    • Tabs with unsaved form input
    • The currently active tab in each window
  • Connectivity awareness: skip suspension when offline.
  • Battery awareness: skip suspension while charging.
  • Whitelist with support for domains, URL substrings, and full regex patterns.
  • Auto-unsuspend when switching back to a suspended tab.
  • Discard mode: use Chrome's built-in memory saving instead of the suspended page — up to 5× more memory freed.
  • Dark and light themes for suspended tab pages.
  • Screenshot preview of the tab before suspension — screen-only or full-page capture.
  • High-quality screen capture mode.
  • Full keyboard shortcut support — 10 configurable shortcuts.
  • Right-click context menu for quick tab suspension, whitelisting, and bulk actions.
  • Session management — save, restore, and export/import sessions with all tab history.
  • Settings sync across devices via Chrome profile sync.
  • Low-memory mode — automatically suspend tabs when system memory is critically low, overriding Chrome's built-in tab discarding.
  • "Open link in new suspended tab" right-click option.
  • Tab recovery page for crash and restart scenarios.
  • Incognito mode support.
